# PCL 更新后无法下载游戏的解决办法

> 方法来源：**尘漠中尘**（QQ 群分享）　整理：chen_pi
>
> 本仓库与 PCL 官方及作者龙腾猫跃无关。请支持正版 Minecraft，也请支持原作者：[爱发电 · 龙腾猫跃](https://afdian.com/a/LTCat)

## 发生了什么

2026-10-20，PCL 发布了 **2.99.0.0**，公告内容为：

> 为遵守相关法律法规，PCL 不再提供 MC 下载功能，非常抱歉 qwq……

从[公开源码](https://github.com/Meloong-Git/PCL)可以看出，下载功能是在 2.99 里通过代码中写死的开关（`RestrictMcDownload = True`）关闭的，不是服务器远程关闭。

**也就是说：2.99 之前的版本仍然可以正常下载游戏，只要不更新就行。**

但 PCL 默认的更新设置是「在有新版本时自动下载」，旧版本打开后很可能会被自动升级到 2.99。如果使用旧版本方案，关键是**关掉自动更新**。

## 无需降级的 Windows 一键修复（2.99.0.0）

已升级到 **PCL 正式版 2.99.0.0 (413)**，也可以保留当前版本，使用 Windows 自带 PowerShell 修复「下载 → 自动安装」页面，无需安装 Python 或其他编程环境。

**工具来源：[caotaiyi / MAKE PCL DOWNLOAD AGAIN!](https://github.com/caotaiyi/make-pcl-download-again)**。本仓库收录来自该项目的 [`MAKE-PCL-DOWNLOAD-AGAIN.cmd`](MAKE-PCL-DOWNLOAD-AGAIN.cmd)，便于直接下载使用。

1. 先关闭 PCL，下载上面的 CMD 文件（文件页右上角的 **Download raw file**）。
2. 双击 CMD 自动查找启动器，或把 PCL 的 `.exe` 拖到 CMD 上。
3. 根据提示选择文件，输入 `y` 确认。工具校验并备份后修复，成功时显示「玩的开心」。
4. 重新打开 PCL，进入「下载 → 自动安装」查看版本列表。

修改前会在启动器旁创建 `.pcl-download-backup` 原版备份。重复运行会跳过已修复文件；也可以在终端中使用：

```bat
:: 只检查，不修改
MAKE-PCL-DOWNLOAD-AGAIN.cmd "D:\Plain Craft Launcher 2.exe" --check

:: 从原版备份恢复（需要确认）
MAKE-PCL-DOWNLOAD-AGAIN.cmd "D:\Plain Craft Launcher 2.exe" --restore
```

**适用范围：**只接受已验证的原文件 SHA-256：`6b6e1260cb5a1d6a303855f1c60cab3d0bc1aebba7e40a964180188b271e7386`。即使版本号相同，文件不匹配也会停止处理。修复的是 MC 自动安装下载页的版本列表加载器，不恢复该版本已删除的整合包安装逻辑。

工具离线运行，不修改账号、注册表、游戏目录或存档，也不分发 PCL 本体。已在真实 PCL 副本上验证修复、重复运行和恢复，尚未验证完整游戏下载。PCL 更新或替换启动器后可能覆盖修复；不匹配的新文件不会被强行修改。

## 解决步骤

### 1. 确认版本

打开 PCL →「更多」→「关于」查看版本号，或者右键 `Plain Craft Launcher 2.exe` → 属性 → 详细信息。

- **低于 2.99.0.0**：继续下面的步骤
- **已经是 2.99.0.0**：可尝试上方[无需降级的一键修复](#one-click-fix)；也可以换回旧版本，见下方「已经更新了怎么办」

### 2. 先备份 exe

把 `Plain Craft Launcher 2.exe` 复制一份到别的文件夹。万一被更新了，可以直接拿备份覆盖回去。

### 3. 关闭自动更新（二选一）

**方法 A：在设置里改**

「设置」→ 左侧「其他」→「启动器」卡片里的「启动器更新」→ 选择 **关闭更新提示**（会弹出警告，点「我知道我在做什么」）。

**方法 B：改配置文件**

用记事本打开 exe 旁边的 `PCL\Setup.ini`，在最后加一行：

```ini
SystemSystemUpdate:3
```

保存即可。也可以直接用本仓库里的 [`Setup.ini`](Setup.ini)（只有这一行）。

> ⚠️ 不要直接拿别人的整个 `Setup.ini` 覆盖自己的，里面的游戏目录、内存等设置会把你自己的冲掉。只加这一行就够了。

### 4. 弹出「悲报」公告时不要点「更新 PCL」

直接关掉公告即可。

### 5. 验证

打开「下载」页，能看到 MC 版本列表并能正常安装，就说明成功了。

## 换 exe 前先备份数据（主题、背景、账号等）

PCL 的数据**不在 exe 里**，分两处存放：

| 数据 | 位置 |
|---|---|
| 当前主题、背景图、音乐、自定义主页、内存等设置 | exe 旁边的 `PCL\` 文件夹（`Setup.ini`、`Pictures`、`Musics` 等） |
| 已解锁的隐藏主题、登录账号、游戏文件夹列表 | 注册表 `HKEY_CURRENT_USER\Software\PCL` |

**换 exe 时只替换 exe 本身，放在原来的文件夹里**，不要删 `PCL\` 文件夹，也不要把新 exe 放到别的地方。这样所有设置都会保留。

> 换完发现主题变回默认、解锁的颜色"没了"？一般是新 exe 放到了别的文件夹，读不到原来的 `Setup.ini`。解锁记录在注册表里，并没有丢：把 exe 放回原文件夹，或者去「设置 → 个性化」重新选一下主题即可。

### 完整备份（重装系统 / 换文件夹前）

1. 复制整个 PCL 文件夹（exe + `PCL\` 文件夹）到别处
2. 按 `Win + R` 打开「运行」，输入 `cmd` 回车，执行：

   ```bat
   reg export HKCU\Software\PCL "%USERPROFILE%\Desktop\PCL注册表备份.reg"
   ```

   桌面上会出现 `PCL注册表备份.reg`。恢复时双击它导入即可。

> ⚠️ 这个 `.reg` 文件里有你的**登录账号凭据**（加密过但仍可用于登录），**千万不要发给别人或上传到网上**。
>
> 解锁记录是加密的，可能和本机绑定，导入到别的电脑上不一定有效。

## 已经更新了怎么办

可以先查看[无需降级的一键修复](#one-click-fix)。不符合工具支持范围，或希望使用旧版方案时，再按下面的方法操作。

用之前备份的旧版 exe 覆盖回去，然后按上面第 3 步关闭自动更新。

本仓库的 [Releases](../../releases) 中提供：

- **[PCL 2.14.0.0（已关闭自动更新）](../../releases/tag/v2.14.0.0)**（推荐）：2.99 之前的最后一个官方正式版，打包好了关闭自动更新的配置，**解压后直接双击就能用**。已实测正版登录、版本列表正常。
  - 已经在用 PCL 的人：只把 exe 换到原来的文件夹里，**不要**用压缩包里的 `PCL` 文件夹覆盖自己的
- [PCL 2.13.1.1](../../releases/tag/v2.13.1.1)：更早的版本，备用

exe 均为官方原版、未修改，Release 页附有 SHA256 可核对。**仅供个人自救使用**，PCL 受《PCL 分发有限许可》约束，如作者要求将立即删除。

## 注意事项

- 关闭更新后，PCL 将来出现严重问题（比如登录方式变化）也不会自动修复，届时需要自己手动处理。
- 下载走的是 Mojang 官方源和镜像源，如果这些源本身不可用，换哪个版本都没用。
- 本教程仅供学习交流，使用造成的任何后果自负。
